## Knowledge

- [DeepSeek Harness architecture](../architecture.md) — the primary map of profiles, bundles, events, the agent loop, session logging, and extension points. Use it before changing `packages/`.
- [Cordis primer](../cordis-primer.md) — the repository's explanation of plugin composition, services, effects, and lifecycle semantics. Use it when a lesson introduces a Cordis mechanism.
- [Event producer and consumer map](../event-producer-consumer.md) — the generated reference for event ownership and consumers. Use it when tracing a runtime fact.
- [Capability seams](../capability-seams.md) — the Service Definition, Provider, and Consumer roles. Use it when designing a plugin boundary.
- [Cordis source repository](https://github.com/cordiverse/cordis) — the upstream framework source and API reference. Use it to verify framework behavior beyond the local primer.
- [DeepSeek Harness repository](https://github.com/deepseek-ai/deepseek-harness) — the upstream project history and public examples. Use it to compare the local checkout with released project context.

## Wisdom (Communities)

- [DeepSeek Harness GitHub Discussions](https://github.com/deepseek-ai/deepseek-harness/discussions) — project-specific questions and usage experience. Use it for questions that source code and documentation cannot settle.
- [DeepSeek Harness Discord](https://discord.gg/Ycq5dCaS4) — real-time project discussion. Use it for maintainer and practitioner feedback after forming a concrete question.
