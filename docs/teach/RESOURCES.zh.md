## 知识

- [DeepSeek Harness 架构文档](../architecture.md) — profile、组合包、事件、agent loop、会话日志和扩展点的主要索引。修改 `packages/` 前使用它。
- [Cordis primer](../cordis-primer.md) — 仓库对插件组合、服务、effect 和生命周期语义的说明。课程介绍 Cordis 机制时使用它。
- [事件生产方和消费方索引](../event-producer-consumer.md) — 事件归属和消费方的生成参考。追踪运行时事实时使用它。
- [能力 seam](../capability-seams.md) — Service Definition、Service Provider 和 Consumer 角色的说明。设计插件能力时使用它。
- [Cordis 源码仓库](https://github.com/cordiverse/cordis) — 上游框架源码和 API 参考。需要验证本地 primer 之外的框架行为时使用它。
- [DeepSeek Harness 仓库](https://github.com/deepseek-ai/deepseek-harness) — 上游项目历史和公开示例。需要将本地 checkout 与公开项目上下文对照时使用它。
